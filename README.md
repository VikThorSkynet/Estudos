# Estudos

Materiais de estudo, exercícios e exemplos de programação organizados por assunto.

| Assunto | Como começar |
|---|---|
| Design Patterns em Python | [Abrir o guia de estudo](<Design Patterns/README.md>) |

O módulo de Design Patterns parte do primeiro programa em Python e avança para orientação a objetos, padrões de projeto, testes, refatoração e resiliência. Leia o guia do módulo para seguir a ordem proposta.

## Método reutilizável

A [skill Estudo gamificado](skills/README.md) permite criar estudos de outros temas com o mesmo método: explicações, exemplos visuais, exercícios, missões e revisão. O guia contém instruções para instalar e usar.
